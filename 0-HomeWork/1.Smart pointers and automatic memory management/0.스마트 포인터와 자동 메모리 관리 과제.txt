설명

1. 과제 목적

C++의 스마트 포인터 개념을 이해하고, 동적 메모리 관리의 문제를 어떻게 개선하는지 분석한다.

또한 reference count의 동작 원리를 설명하고, Java Virtual Machine 기반의 메모리 관리 방식과 비교하여 C++의 자동 메모리 반환 방식의 장단점을 비판적으로 정리한다.


2. 과제 주제

다음 내용을 포함하여 보고서 형식으로 작성하시오.

+ 스마트 포인터의 개념과 필요성

  - 일반 포인터를 사용할 때 발생할 수 있는 문제

  - 스마트 포인터가 이러한 문제를 어떻게 완화하는지 설명

+ reference count의 원리

  - reference count가 무엇인지 설명

  - shared_ptr에서 reference count가 어떻게 증가·감소하는지 설명

  - reference count 기반 관리 방식의 장점과 한계 정리

+ Java Virtual Machine(JVM)과의 연관성

  - JVM에서의 메모리 관리 방식(예: Garbage Collection) 개요

  - C++ 스마트 포인터 기반 관리와 JVM의 자동 메모리 관리의 공통점과 차이점 비교

  - 개발자 관점에서 두 방식이 갖는 의미 설명

+ 메모리 자동반환의 장단점

  - 장점: 코드 안정성, 메모리 누수 감소, 예외 상황 대응 등

  - 단점: 성능 오버헤드, 제어의 어려움, 순환 참조 문제 등

  - 자동반환 방식이 항상 최선인지에 대한 자신의 의견 제시
